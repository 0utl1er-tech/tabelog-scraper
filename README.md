# 食べログスクレイパー

関数型プログラミングを意識したTypeScriptベースの食べログスクレイピングツールです。

## 機能

- 食べログの店舗ページから以下の情報を抽出：
  - 店舗基本情報（店舗名、評価、価格帯、住所など）
  - 席・設備情報（席数、個室、喫煙、駐車場など）
  - メニュー情報（ランチ、ディナー、ドリンクなど）
  - 特徴・関連情報（特徴、雰囲気、利用シーンなど）
- CSVファイルからのURL一括読み込み
- 結果のCSV出力
- エラーハンドリングとリトライ機能
- 関数型プログラミングパターンの採用

## セットアップ

1. 依存関係のインストール：
```bash
npm install
```

2. TypeScriptのビルド：
```bash
npm run build
```

## 使用方法

1. `import.csv`ファイルにスクレイピング対象のURLを記入：
```csv
urls
https://tabelog.com/tokyo/A1303/A130303/13313934/
https://tabelog.com/tokyo/A1303/A130303/12345678/
```

2. スクレイピング実行：
```bash
npm run scrape
```

または開発モードで実行：
```bash
npm run dev
```

## 出力ファイル

- `output/tabelog_data_YYYY-MM-DDTHH-mm-ss.csv`: スクレイピング結果
- `output/error_log_YYYY-MM-DDTHH-mm-ss.csv`: エラーログ（エラーが発生した場合）

## 技術スタック

- **TypeScript**: 型安全性の確保
- **Puppeteer**: ブラウザ自動化
- **fp-ts**: 関数型プログラミングライブラリ
- **io-ts**: ランタイム型検証
- **csv-parser/csv-writer**: CSVファイルの読み書き

## 関数型プログラミングの特徴

- **Either/TaskEither**: エラーハンドリング
- **Option**: null安全性
- **pipe**: 関数合成
- **不変性**: データの変更を避ける
- **純粋関数**: 副作用の分離

## 注意事項

- 食べログの利用規約を遵守してください
- 過度なリクエストは避け、適切な間隔を空けてください
- スクレイピング対象のサイトの構造変更により動作しなくなる可能性があります
